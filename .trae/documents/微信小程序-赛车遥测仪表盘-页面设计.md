# 页面设计（Desktop-first：优先适配大屏/横屏，兼容手机）

## 全局设计规范

### Layout
- 基础栅格：内容容器 `max-width: 960rpx`（大屏居中），两侧留白自适应；手机端满宽。
- 主要布局：纵向分区（Stacked Sections）+ 卡片化信息；详情页在大屏下可采用“两列布局（左图右图/右侧控制面板）”。
- 间距：8/12/16/24rpx 四档；卡片内边距 16rpx。

### Meta Information
- 默认标题：
  - 首页：`遥测仪表盘`
  - 详情：`会话详情`
  - 设置：`设置与接入`
- 描述（用于分享卡片/分享消息摘要）：`赛车遥测趋势与关键指标查看`。

### Global Styles（TDesign 风格对齐）
- 背景：`#F6F7F9`；内容卡片：`#FFFFFF`。
- 主色：跟随 TDesign 默认品牌色（不自定义色值）；强调色用于选中态与图表主线。
- 字体层级：
  - 标题：加粗 32rpx
  - 分组标题：28rpx
  - 正文：26rpx
  - 辅助：24rpx
- 交互：按钮/单元格遵循 TDesign 默认 hover/active；图表区域点击命中用透明遮罩避免误触。

### 图表通用规范（ECharts-for-Weixin）
- 统一 X 轴：优先 `distance`（米/公里），否则用 `t`（秒）。
- Tooltip：axisPointer 为 cross；多图联动时共享同一游标位置。
- 性能：数据点>3000 时先做下采样（services/telemetryService）；缩放/拖动更新节流（utils/throttle）。
- 主题：在 services/optionFactory 统一生成 option（颜色、网格、字体、轴线）。

## 页面 1：首页（遥测仪表盘）

### Page Structure
- 顶部导航（固定）
- 会话选择区（卡片）
- KPI 区（横向滚动卡片）
- 图表预览区（Tabs + 卡片）
- 记录列表区

### Sections & Components
1. 顶部导航
   - `t-navbar`：标题“遥测仪表盘”，右侧入口“设置”。
2. 会话选择区
   - `t-card` + `t-cell`：车辆/赛道/会话三项；点击弹 `t-picker`。
   - 状态：加载中 `t-loading`；无数据 `t-empty`。
3. KPI 区
   - 横向 `scroll-view` + 自定义 `telemetry-kpi-card`（内部用 `t-card`/`t-tag`）：速度、转速、油门、刹车、档位、圈速。
4. 图表预览区
   - `t-tabs`：
     - Tab1「动力」：速度&转速双轴折线（同图或上下两图）。
     - Tab2「踏板」：油门/刹车面积图。
     - Tab3「圈速」：按圈趋势折线。
   - 每个 Tab 内：`t-card` + `ec-canvas`；点击卡片跳转详情页并带入 sessionId。
5. 记录列表区
   - `t-cell-group`：展示会话名称、时间、圈数、数据完整度；点击进入详情。

### Responsive behavior
- 宽屏（横屏/平板）：KPI 与预览图可改为两列（左 KPI+列表，右 图表）。

## 页面 2：遥测详情页

### Page Structure
- 顶部导航（返回 + 标题）
- 顶部摘要（会话信息 + 关键指标）
- 控制区（通道开关/视图切换）
- 图表区（多图联动）

### Sections & Components
1. 顶部导航
   - `t-navbar`：标题显示会话名/赛道；返回。
2. 顶部摘要
   - `t-card`：展示圈数、数据范围（时间/距离）、速度峰值等（复用首页 KPI 的子集）。
3. 控制区
   - 自定义 `telemetry-channel-switch`（内部 `t-checkbox-group`/`t-switch`）：选择显示通道。
   - `t-segmented-control`（或 tabs）：X 轴选择「距离/时间」（若数据支持）。
4. 图表区（建议 3 张）
   - 图 1：速度（主）+ 转速（次，双轴）
   - 图 2：油门/刹车
   - 图 3：档位阶梯（step）或圈速
   - 交互：
     - dataZoom 缩放；双指/滑块（按 echarts-for-weixin 能力实现其一即可）
     - tooltip 游标联动（同一 index）；点击图例开关系列
   - 状态：渲染失败/数据缺失用 `t-toast` + `t-empty`。

### Responsive behavior
- 宽屏：右侧固定控制面板（通道开关），左侧图表纵向排列；手机端控制区置顶、图表置底。

## 页面 3：设置与接入页

### Page Structure
- 分组列表（卡片化）

### Sections & Components
1. 外观与行为
   - `t-cell-group`：
     - 主题：`t-radio-group`（浅色/深色，默认浅色）
     - 刷新策略：进入页刷新/实时刷新（二选一，默认进入页刷新）
2. ECharts 检测
   - `t-card` + 小型 `ec-canvas`：渲染测试折线；显示“通过/失败与原因”。
3. 数据接入说明
   - `t-card`：展示最小字段示例（session 与 samples）；提供“复制示例 JSON”（调用 `wx.setClipboardData`）。

### Interaction states
- 设置项保存后用 `t-toast` 提示；回到首页时自动应用主题/策略。
